# Power Automate build handoff

This server cannot create or modify cloud flows. Use it to discover environments, connections, connectors and existing static action metadata, then hand the build to a Microsoft-supported solution ALM or Power Automate authoring surface.

Do not fabricate REST endpoints or connector operation IDs. Any implementation plan must include explicit inputs/outputs, same-solution/environment constraints, connection references, error paths, timeout/retry behavior, human review, rollback and post-deployment verification.
