## 開始上課

1. 開啟對應課程手冊，確認角色、案件與目前情境時間。
2. 新建 Cowork 任務，只加入資料 A；進行到指定步驟才加入 B、C。
3. 依每步提示詞的截至時間使用資料。不要把含參考答案的完整手冊上傳作為案例輸入。
4. 產出後對照來源、日期、ID、數值、版本及狀態；缺漏使用具體修訂指令。
5. 完成八步後依五項評量驗收。HTML 手冊可下載資料夾後開啟，參考成果可展開閱讀。

案例公司、人員、交易、工單與數據皆為合成練習資料。課堂預設產出草稿；正式寄送、系統寫入及 IT 執行需有實際工具、連線、權限與批准。財務數值用於教學核對，不能作為實際入帳或付款依據。

簡報的操作頁取自官方公開產品畫面並加上教學標註，並非本案例在租戶中的執行截圖。功能條件與畫面來源列於各課手冊。驗證案例是待執行的行為評量規格；程式庫靜態驗證通過不代表 Cowork 租戶實測通過。
