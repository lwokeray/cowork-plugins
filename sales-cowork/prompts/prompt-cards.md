# Sales Cowork Prompt Cards

以下內容供 Microsoft 365 admin center 的 Copilot Prompt 建立頁面使用。所有 Prompt Card 均設定：

- 支援的應用程式：`Copilot Cowork`
- 部門：`銷售`
- 語言：`Chinese Traditional｜中文（繁體）`

完整欄位及可複製提示位於 [prompt-cards.csv](prompt-cards.csv)。

| 標題 | 顯示提示 | 工作類型 | 對應 Skill |
|---|---|---|---|
| 規劃今日銷售重點 | 整理今天最重要的三項銷售行動 | 掌握近況 | `daily-sales-rhythm` |
| 評估新進銷售線索 | 分析最近收到的新線索並提出下一步 | 分析 | `lead-intake-qualification` |
| 研究目標客戶 | 彙整指定客戶的內部證據與待確認問題 | 尋找 | `account-research` |
| 分析市場與競爭態勢 | 分析指定市場、競爭者與銷售影響 | 分析 | `market-competitive-research` |
| 建立客戶經營計畫 | 建立指定客戶的關係、目標與行動計畫 | 設計 | `account-plan` |
| 準備客戶會議 | 為指定客戶會議建立證據導向會前簡報 | 準備 | `customer-meeting-brief` |
| 整理會後追蹤 | 整理會議紀要、客戶信件及 Planner 工作 | 建立 | `meeting-follow-up` |
| 設計商機推進策略 | 建立商機決策地圖、風險與下一步策略 | 設計 | `opportunity-strategy` |
| 檢查商機健康度 | 找出商機阻礙、證據缺口與安全下一步 | 分析 | `deal-inspection` |
| 執行客戶互動 | 準備並執行核准的客戶聯繫與會議安排 | 執行 | `sales-outreach-engagement` |
| 安排銷售工作 | 建立或更新核准的 Microsoft Planner 工作 | 排程 | `sales-task-planning` |
| 清理銷售工作區 | 找出並修正 Pipeline 工作區的資料問題 | 編輯 | `pipeline-workspace-hygiene` |
| 準備預測決策包 | 比較核准快照並整理 Forecast 決策問題 | 分析 | `forecast-decision-pack` |
| 準備解決方案提案 | 建立需求、證據、方案與交付範圍草案 | 準備 | `proposal-preparation` |
| 檢查商務風險 | 整理價格、法務、資安與核准事項 | 分析 | `commercial-review-handoff` |
| 準備成交交付交接 | 整理成交證據、承諾、Owner 與交付依賴 | 準備 | `close-delivery-handoff` |
| 掌握續約與擴展機會 | 檢視採用、承諾、風險與續約擴展訊號 | 掌握近況 | `renewal-expansion-review` |
